## 决策原则

1. **可复现优先于便利**：任何让"同一操作产生不同结果"的实现便利，一律否决。
2. **可测优先于可读**：纯逻辑必须能脱离引擎运行，否则平衡无法自动化验证。
3. **为联机留口，不为联机付账**：架构支持多行动者，但 MVP 不实现网络。
4. **不确定的就不写死**：超出 AI 训练数据的引擎行为，标记为"待验证"并列入人工核对清单。
5. **ADR 不静默改写历史**：引擎级决策被推翻时，旧 ADR 标记"已废止"并新增编号，不把旧结论改成新结论。
