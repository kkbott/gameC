## 概述

P1 把手势翻译成命令：按下部件、拖到田里、松手。它不判断对错（C3 管），不改状态（F2 管），但它决定了这个游戏**摸着是什么手感**。

一个关键约束：**Steam 上架必须有手柄支持**。而"拖拽"在手柄上几乎不可用——所以 P1 必须提供**两套等价的输入模型**，而不是把鼠标方案硬套到手柄上。

---

## 玩家幻想

> **「手上有字，地就在手边。」**

- 拖拽应该**沉**：部件被"拿起来"时有重量感，落下去有顿感。
- 磁吸要**自然**，不能像被系统抢走——玩家感觉到"是我放进去的"。
- 手柄玩家不能感觉自己玩的是"降级版"。**两种输入必须同样顺手。**

---

## 详细设计

### 核心规则

**R1 · 手势到命令的唯一通道**

```
手势/按键 → InputIntent（表现层）→ 命令对象（F2）→ State
```

表现层**不得直接改状态**。P1 的产出永远是 `ComposeCharacterCommand` / `ClearSuiCommand` / `EndRoundEarlyCommand` 等。

**R2 · 鼠标/触控模型：拖拽**

```
1. 按住手牌中的部件 → 该部件被"提起"（跟随指针，略微放大 + 投影）
2. 拖动期间若指针进入某个 `Empty` 田 → 显示预览框（内容受 C3 R6 约束）
3. 松手：
     落在合法田 → 若该田已有 1 个部件则组成组合并提交命令；否则暂存该部件在田边
     落在非法区 → 回弹到手牌，不消耗、不报错
4. 拖拽中按右键/Esc → 取消
```

**R3 · 田块命中与磁吸**

- 命中判定用**最近田块 + 半径阈值**（约 0.6 格距），不要求精确落在格内。
- 磁吸只在"最近田块是 `Empty` 或 `Char`（用于查看）"时生效；磁吸到 `Sui` 时显示"需先清除"而非吸附。
- **磁吸不得超过一格**，防止玩家想写 A 田却被吸到 B 田。

**R4 · 手柄模型：网格选择（两段式）**

手柄上不做拖拽，改用**选目标 → 选部件**的两段式，操作步数相同：

```
① 十字键/左摇杆 → 在 4×3 田格间移动光标（上下左右，边界不环绕）
② 肩键 L/R 或右摇杆 → 在手牌间切换当前部件
③ A 键 → 选定第一个部件（田格高亮"待定"）
④ 换部件 + A → 组成组合并提交
⑤ B 键 → 取消当前选择
⑥ X 键 → 清祟字          Y 键 → 提前结束回合
```

**等价性要求**：手柄必须能用与鼠标**相同的步数**完成一次布字（3 步：选田/选部件 1/选部件 2）。允许两步，不允许四步。

**R5 · 输入抽象**

```csharp
public interface IInputModel
{
    // 两套实现：PointerInputModel / GamepadInputModel
    void Poll(InputSnapshot frame, ICommandSink sink);
}
```

- 用 Godot `InputMap` 动作 + `InputEvent`，不直接读按键扫描码 / 硬编码设备键位。
- **手柄与键鼠可热插拔**：最后一个有输入的设备决定 UI 提示图标。

**R6 · 预览的可见性（严格受 C3 R6 约束）**

| 组合状态 | 预览显示 |
| --- | --- |
| 农书已收录 | 字 + 效果 |
| 未收录 | "没写过"（**不显示成败**） |

> P1 **不得**自行推出"这个组合是否有效"来给提示。预览数据只能来自 C3 的 `canPreview`。这一条是防"表现层偷偷给答案"。

**R7 · 无障碍**

- 成功/失败**不能只靠颜色**区分：必须叠加动势（合流 vs 溅开）与音效差异。
- 提供"减少动效"选项（P4/M5 落地前先留开关位）。

### 状态和转换

```
Idle --[按下部件]--> Dragging --[进入合法田]--> Previewing
Previewing --[松手]--> Submitting --[命令成功]--> Idle
Previewing --[松手在非法区]--> Idle (回弹，无消耗)
Dragging --[Esc/右键]--> Idle
Dragging --[锁定期间]--> Idle (立即回弹 + 提示"今晚写不了")
```

### 与其他系统的交互

| 系统 | 方向 | 接口 | 所有权 |
| --- | --- | --- | --- |
| C1 田块 | 上游 | 读布局、`PlotStatus`、命中判定 | C1 拥有布局 |

## 公式

```
拖拽判定：hitPlot = argmin(distance(pointer, plot.center))  if distance < 0.6 × spacing
磁吸半径：0.6 × plotSpacing
手柄步数预算：≤ 3 步完成一次布字
```

## 边缘情况

| # | 情况 | 处理 |
| --- | --- | --- |
| E1 | 拖拽中触发祟夜（字格锁定） | 立即回弹 + 提示，命令不下发 |
| E2 | 拖拽中手牌被补牌（不该发生，补牌只在回合开始） | 若发生，保持提起的部件引用不失效（按 `GlyphId` 而非索引） |
| E3 | 手柄与鼠标同时操作 | 以最后有输入的设备为准，切换 UI 提示，不重复提交命令 |
| E4 | 拖到 `Sui` 田 | 不吸附，显示"先清祟字"，提供一键清除快捷（若铜钱够） |
| E5 | 拖到 `Locked` 田 | 不吸附，显示开垦成本 |
| E6 | 手牌不足 2 张时拖拽 | 允许提起（可查看），松手时拒绝并提示（C3 的 `not_enough_parts`） |
| E7 | 触屏拖拽与滚动冲突 | 手牌区横向滑动与提起拖拽用长按区分（>150ms） |

## 视觉/音频需求

- 提起：部件微微抬起、投影出现、纸面轻响。
- 磁吸：田块边框亮起，部件向格中心吸附（缓动 100ms，不可瞬移）。
- 落定：顿感 + 低沉落纸声。
- 回弹：快速的弧线返回，带一声轻微的纸弹声。
- 细则归 P5 / P6。

## UI需求

- 键鼠与手柄的提示图标要**动态切换**（检测最后输入设备）。
- 田格光标在手柄模式下必须**清晰可见**（不只是高亮边框）。
- 拖拽期间手牌区不可滚动。

## 验收标准

- [ ] **A1** 所有手势最终只产出 F2 命令；静态检查 P1 内无直接写 `FarmState`
- [ ] **A2** 预览数据只来自 C3 `canPreview`；静态检查 P1 内无字表查询
- [ ] **A3** 磁吸半径生效且不跨格（构造相邻两田用例）
- [ ] **A4** 落在非法区回弹，手牌与状态零变化
- [ ] **A5** 字格锁定期间拖拽立即回弹并提示，命令不下发（E1）
- [ ] **A6** 手柄可在 ≤ 3 步内完成一次布字（实测计数）
- [ ] **A7** 键鼠与手柄热插拔切换提示图标，不重复提交命令（E3）
- [ ] **A8** 成功/失败反馈在不看颜色的情况下可区分（灰度截图人工验收）
- [ ] **A9** 减少动效开关关闭所有非必要动效
