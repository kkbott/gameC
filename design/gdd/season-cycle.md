> **上游**: [C5 经济](economy.md)、[C7 祟夜](sui-night.md)、[F3 状态层](farm-state.md)、[F4 存档](save-system.md)

## 概述

G4 是**时间的执行者**。它规定一年怎么过：四季、每季几回合、回合怎么结算、季末清什么、什么时候算通关。

它是四条支柱里最硬的那条——**P4「一季不回头」——唯一能落地的地方**。没有 G4，其他系统都成立，但"不可逆"只是一句口号。

---

## 玩家幻想

> **「今年就这样了。」**

- 季末应该有**翻页感**，像合上一本书，而不是弹个结算面板。
- 玩家在季末会做两件事：回头看（"早知道那块地我该写休"）、往前看（"明春先扩两块"）。
- 冬天的最后一场祟守住时，应该有**一整年走完的重量**，不是"Game Clear"三个字。

---

## 详细设计

### 核心规则

**R1 · 一局 = 一年 = 四季**

```
SeasonIndex: 0 春 / 1 夏 / 2 秋 / 3 冬
每季回合数 roundsPerSeason = 7（初值，可调 6–8）
一局总回合 ≈ 28
```

**R2 · 回合流程（唯一的推进节拍）**

```
RoundStart
  ├─ C2 补牌至 Capacity
  └─ 记录回合起点 hash（调试用）
PlayerActions（多次 Compose / ClearSui / EndRoundEarly）
EndRound
  └─ RoundResolveCommand，按 F2 R5 固定顺序：
       1 命令效果 → 2 产出结算(C4→C5) → 3 祟气(C6)
       → 4 祟夜触发判定(C6) → 5 祟夜结算(C7)
       → 6 村民去留(G2/MVP 空) → 7 季末判定(G4)
NextRound | SeasonEnd
```

**R3 · 季末结算清单（按序执行）**

| 序 | 动作 | 归属 |
| --- | --- | --- |
| 1 | 所有 `Char` 田转 `Empty`；`RemainingRounds` 清零 | C1 R6 |
| 2 | **地力不重置**（跨季累积，C5 的可持续性靠它） | C5 |
| 3 | `Sui` 田**不清**——必须玩家自己清（否则占格惩罚被免费清除） | C3 |
| 4 | 手牌清空，`Capacity += 1`（上限 8） | C2 R6 |
| 5 | 字灵结契结算（G3 落地前为记日志） | G3 |
| 6 | 村民结算（G2 落地前为空） | G2 |
| 7 | `SeasonIndex += 1`；若已是冬季 → 进入通关判定 | G4 |
| 8 | 自动存档（F4 R4） | F4 |
| 9 | 结算画面（P7） | P7 |

**R4 · 不可回退（硬约束）**

- **没有**撤销、没有回合回滚、没有"读档重来本季"。
- `.bak` 存档只在**损坏时**自动回退，不作为玩法手段（F4 R4）。
- 玩家唯一的"重来"是**开新局**。
- 季末结算一旦开始执行，**中间不可中断**（原子 Step；崩溃则回退到季末前的自动存档，重放同一序列结果一致）。

**R5 · 季相系数（提供给 C7 与 C6）**

```
seasonCoef = { 春: 0.90, 夏: 1.00, 秋: 1.15, 冬: 1.30 }     // 归 C7 使用
BASE[季]   = 祟夜敌力基数，见 C7 R3
```

G4 只**提供** `SeasonIndex`，不参与难度计算——系数与基数的实现归 C7。

**R6 · 通关判定（冬季季末）**

```
守住冬末最终祟夜（C7 三波全守）→ 通关
未守住 → 不 Game Over，而是：秋季重来？→ 不。见 R7「残季」
```

**通关不等字谱完成**：字谱完成度作为**附加成就**（"写完你的农书"），不阻塞通关。第一款游戏，主线的门槛要低。

**R7 · 残季（避免硬 Game Over）**

概念 §7 要求"给翻盘的窄路而不是直接 Game Over"。落地为：

```
触发条件：村民数 <= 2
效果：
  - 本季剩余回合的 C7 敌力 E × 1.25
  - 每波毁田数 +1
  - 无法开垦（铜钱仍可用来清祟字）
解除：下一季开始时自动解除（村民不回升，但压制取消）
```

> **⚠️ 已否决"田块缩减"**（原概念 §7 的表述）：C1 的田块是**固定索引**（`index = row*4+col`，4×3 = 12 格）且进存档、参与邻接计算。删格会同时破坏存档兼容、邻接表与 C6 的空田计数，代价远大于收益。
>
> 改为用**两倍压力**表达"残季"：`E × 1.25` + 每波毁田 +1 + 禁止开垦。玩家感受到的是"地还在，但守不住了"，这比"地少了"更贴 P4 的痛感——**毁掉的田不会消失，会变成焦土留在地里**。

**永不出现"游戏结束"屏**。最坏情况是地瘦、人少、年年苦守——但那仍然可玩、可翻盘。这是本作对第一款游戏的最大让步：**不给玩家一个被判死刑的画面**。

### 状态和转换

```
SeasonStart --[7 回合]--> SeasonEnd --[S0..S2]--> SeasonStart
SeasonEnd --[S3 且守住冬末大祟]--> GameWon
SeasonEnd --[S3 未守住]--> EndlessWinter（可继续，无通关标记）
村民<=2 --[任意时刻]--> ResidualSeason --[下季开始]--> 解除
```

### 与其他系统的交互

| 系统 | 方向 | 接口 | 所有权 |
| --- | --- | --- | --- |
| C1 / C2 / C5 | 下游 | 季末执行洗田、扩容、地力保留 | 各自规则，G4 编排 |
| C6 / C7 | 下游 | 冬季最后一场祟的结算 | G4 触发 |
| F2 步进 | 上游 | 结算顺序第 7 步（季末判定） | G4 挂载 |
| F4 存档 | 下游 | 季末触发自动存档 | G4 决定时机 |

## 公式

### 4.1 时间结构

```
一局 = 4 季 × 7 回合 = 28 回合 + 4 次季末 + 约 4–8 次祟夜
预计一局时长：6–8 小时（含思考与重开）
```

### 4.2 残季判定

```
isResidual = villagers <= 2
E_multiplier = isResidual ? 1.25 : 1.0
destroyBonus = isResidual ? +1 : 0
```

### 4.3 通关

```
won = (SeasonIndex == 3) && (seasonEndNightFullyHeld)
```

## 边缘情况

| # | 情况 | 处理 |
| --- | --- | --- |
| E1 | 季末与祟夜同回合 | 祟夜（第 5 步）先于季末（第 7 步）；刚被毁的田在季末**不清**（`Sui` 保留） |
| E2 | 玩家在季末结算中途退出 | 原子 Step，不回退到中途；重开后回到季末前自动存档，重放结果一致 |
| E3 | 冬季最后一场祟从未触发（祟气没满） | 冬末**强制**触发一场大祟（`BASE` 达标即触发），否则没有高潮 |
| E4 | 玩家在第 7 回合提前结束所有操作 | `EndRoundEarly` 合法；空转回合会更糟（祟气按空田算），是真实取舍 |
| E5 | 残季期间村民继续下降 | 下限 2，不再降 |
| E6 | 通关后继续玩 | 进入"无尽冬"：无通关标记，季节循环，用于收集字谱。不影响存档 |
| E7 | 手牌容量已 8 时季末 | 不增加，不溢出 |

## 依赖关系

| 方向 | 系统 | 契约 |
| --- | --- | --- |
| 上游 | F2 步进 | 硬依赖：结算顺序第 7 步 |
| 上游 | F3 状态层 | 硬依赖：`SeasonIndex` / `RoundIndex` |
| 下游 | C1 / C2 / C5 / C6 / C7 | G4 编排它们的结算，但不实现其规则 |
| 下游 | F4 / P7 / G2 / G3 | 存档时机、结算画面、结契钩子 |

**双向一致性**：C7 的 `seasonCoef` 与 `BASE` 已在 C7 定义；G4 只提供 `SeasonIndex`。C1 R6 的洗田规则由 G4 在第 1 步调用。

## 调整旋钮

| 旋钮 | 初值 | 安全范围 | 太高会怎样 | 太低会怎样 |
| --- | --- | --- | --- | --- |
| 每季回合数 | 7 | 6–9 | 一局太长，节奏拖 | 地力/祟气来不及发酵，深度流失 |
| 季数 | 4 | 4–6 | 内容量激增，一个人做不完 | 太短，地力跨季累积不成立 |
| 手牌容量季末 +1 | +1 | 0–1 | 后期选项爆炸 | 手牌永远是 5，成长感缺失 |
| 残季 `E` 倍数 | 1.25 | 1.1–1.5 | 残季变必败 | 残季无痛，惩罚虚设 |
| 冬末强制大祟 | 开 | 开/关 | 关则可能没有高潮 | 开则可能被玩家视为硬性剧情关 |

## 视觉/音频需求

- 季末**必须有翻页/合书的动势**，不是弹窗。
- 四季转换要有一次完整的转场（色盘切换 + 环境音过渡），这是"一季不回头"的情绪锚。
- 冬末守住那一刻：天光变化 + 字灵说一句很长的话（全游戏唯一一次）。
- 细则归 P5 / P6 / P3。

## UI需求

- 季末结算屏要展示：本季收支、地力变化、祟夜次数、字谱新增。
- **不需要**"是否确认结束本季"的二次确认——P4 不允许犹豫，确认框会让玩家以为能反悔。
- 残季状态必须有明显但不羞辱的提示（"今年难了"），而不是红字警告。

## 验收标准

- [ ] **A1** 每季 7 回合后自动进入季末；四季后进入通关判定
- [ ] **A2** 季末清单 9 步按序执行，`Sui` 田不被清、地力不重置（E1 用例）
- [ ] **A3** 手牌容量每季 +1，上限 8，不溢出（E7）
- [ ] **A4** 无任何回退路径：静态检查 UI 层无"撤销/回档"入口；`.bak` 仅损坏时使用
- [ ] **A5** 冬季最后一场祟强制触发（E3 用例）
- [ ] **A6** 残季：村民 ≤ 2 时 `E × 1.25`、毁田 +1，下季自动解除（R7 用例）
- [ ] **A7** 永不出现 "Game Over" 屏（UI 检查）
- [ ] **A8** 通关条件 = 冬季季末且三波全守；字谱完成度不影响通关（R6）
- [ ] **A9** 季末触发自动存档，且存档点不含季末中间态（与 F4 A4 联动）
- [ ] **A10** 无尽冬模式可无限循环且存档正常（E6）
