> **上游**: [F3 状态层](farm-state.md) v0.1、[F2 确定性步进](deterministic-step.md) v0.1

---

## 概述

C1 定义**玩家能写字的地方**：12 块田，每块就是一个字格。它规定田块的身份、位置、相邻关系、状态与寿命。

它不规定"田里写什么字"（那是 C3/C4），也不规定"收成怎么算成钱"（那是 C5）。它只回答一个问题：**这片地有多少个可写的位置、它们怎么连在一起、什么时候会空出来。**

整个游戏的选择空间就是这 12 个格子。**田块是核心稀缺资源**，所有惩罚（失败占格、祟夜毁田）和所有成长（开垦）都在它上面发生。

---

## 玩家幻想

> **「这十二块地，是我的字纸。」**

玩家应该感觉到田块是**有历史的地方**，不是抽象槽位：

- 每块田有自己的位置感：北边临水的那块适合写 `江`，南边背风的适合写 `林`。
- 被祟烧过的田会留痕（焦土），玩家会记得"这块去年毁过"。
- 开垦新田是**扩张感**的来源，不是数值上限的解锁。

## 详细设计

### 核心规则

**R1 · 田块身份固定**

```
田块索引 PlotIndex ∈ [0, 11]，布局 4 列 × 3 行：
  index = row * 4 + col
位置由索引唯一确定，玩家不能自由摆放田块。

初始解锁 6 块：index 0..5（前一行半）
其余 6 块：index 6..11，状态 Locked
```

> 沿用《穗守》原型已验证的 4×3 布局（`cols: 4, rows: 3`），这是唯一从原型继承的资产——省掉一次布局验证。

**R2 · 田块状态（与 F3 一致）**

| 状态 | 可写 | 有产出 | 可被摧毁 |
| --- | --- | --- | --- |
| `Locked` | 否 | 否 | 否 |
| `Empty` | 是 | 否 | 否 |
| `Char` | 否（需先清） | 视模板 | 是 |
| `Sui` | 否（需先清） | 否 | 否 |

**R3 · 开垦**

- 从 `Locked` → `Empty`，按索引**顺序**解锁（不能跳块）。
- 成本递增曲线：`unlockCost[i] = [25, 35, 50, 65, 85, 110][i]`，`i` 为第几次开垦（0 起）。
- 开垦是一次普通命令，走 F2 通道，校验铜钱余额。
- **已开垦田块数进入祟夜敌力公式**（概念 §6），因此扩张自带代价。

**R4 · 相邻关系**

邻接**由索引与行列计算**（4 邻域，越界裁剪），不手工维护邻接表：

```
neighbors(i) = { i-1 if col>0, i+1 if col<3, i-4 if row>0, i+4 if row<2 }
```

用于 `adjacent_boost` 模板（C4）。相邻加成**只跳一跳**，不传递。

> 为什么计算而非配置：确定性优先。手写邻接表会因编辑错误导致回放分歧，而公式计算不可能错。

**R5 · 字的寿命**

| duration | 寿命 | 到期动作 |
| --- | --- | --- |
| `instant` | 当步生效后立即失效 | 田转为 `Empty`（若是 `single_ripen` 这类纯产出模板，字消失） |
| `rounds:N` | N 个回合 | 每回合结算 `RemainingRounds--`，归零转 `Empty` |
| `season` | 本季内 | 季末洗田，统一转 `Empty` |

**R6 · 季末洗田**

所有 `Char` 田转 `Empty`，`RemainingRounds` 清零，`AppliedRound` 清零。**地力不重置**（那是 C5 的事）。

**R7 · 焦土留痕（纯表现，不是状态）**

被祟夜摧毁的田记入**表现层**的焦土集合（`PlotHistoryMeta`），不影响规则。规则层不需要"这块以前毁过"——所以不放进 `FarmState`。

> 这条是给 P5 的授权：焦土可以有，但**不能变成规则状态**，否则玩家会尝试用它做预测，把氛围变成机制。

### 状态和转换

```
Locked --[开垦命令, 扣铜钱]--> Empty
Empty  --[C3 成功分支]--> Char
Empty  --[C3 失败分支]--> Sui
Char   --[duration 到期 / 季末洗田]--> Empty
Char   --[祟夜摧毁]--> Sui
Sui    --[3 铜钱清除 / clear_sui 字效 / 兜底]--> Empty
```

### 与其他系统的交互

| 系统 | 方向 | 接口 | 所有权 |
| --- | --- | --- | --- |
| F3 状态层 | 上游 | 提供 `Plot[]`、`PlotStatus`、`Soil` | F3 拥有数据，C1 拥有规则 |
| F2 步进 | 上游 | 开垦命令、洗田结算命令 | C1 拥有命令类型 |
| C3 合字校验 | 下游 | C3 写入田状态；C1 提供 `CanWrite(plotIndex)` 校验 | C3 拥有判定，C1 拥有"能不能写" |
| C4 字效 | 下游 | 读 `neighbors(i)`、`RemainingRounds` | C1 提供空间与寿命 |
| C5 经济 | 下游 | 开垦扣款；地力变化归 C5 | C5 拥有货币与地力规则 |
| C6 祟气 | 下游 | 读 `Locked`/`Empty` 田块数（空田积祟气） | C6 拥有公式 |
| C7 祟夜 | 下游 | 读已开垦田块数（进敌力公式）；写入摧毁 | C7 拥有判定 |
| P2 / P5 | 下游 | 读布局与状态做渲染 | — |

> **注意 C1 与 C5 的地力边界**：`Soil` 字段在 F3 里（因为要存档），但**怎么变是 C5 的规则**。C1 只保证它存在且范围 0..100。这是"字段归状态层、规则归系统"的典型切分，别搞混。

## 公式

### 4.1 开垦成本

```
unlockCost(i) = COST_TABLE[i]        // [25, 35, 50, 65, 85, 110]
i = 已开垦次数 − 6                   // 初始 6 块不算
累计成本（开满 12 块） = 370 铜钱
```

### 4.2 邻接

```
col(i) = i mod 4      row(i) = floor(i / 4)
neighbors(i) = 见 R4，越界裁剪
邻接数：角落 2 / 边 3 / 内部 4
```

### 4.3 可用书写位

```
writableSlots(s) = count(Plots where Status == Empty)
```
这是 C2 发牌与 C3 布局压力的共同输入。

## 边缘情况

| # | 情况 | 处理 |
| --- | --- | --- |
| E1 | 铜钱不足时开垦 | 命令被拒，不扣款，不改变状态 |
| E2 | 全部 12 块已开垦 | 开垦命令被拒，提示"地就这么多了" |
| E3 | 全部田块为 `Sui` | **不直接 Game Over**：走 C3 §R5 的兜底（下次成功合字清一祟字）。但若手牌也枯竭 → 触发 C6 强制祟夜，把局面推向结算而不是让玩家卡死 |
| E4 | `adjacent_boost` 相邻两块互相加成 | **允许叠乘**，但受 C4 的叠加上限约束（不超过 ×2.5）。防止两两相邻形成无限放大 |
| E5 | `rounds:N` 效果在回合中途到期 | 只在回合结算步推进，不会中途失效 |
| E6 | 洗田时该田正处于祟夜结算中 | 顺序固定：祟夜先结算，洗田在后（F2 R5 第 5 步先于第 7 步） |
| E7 | 读档后 `RemainingRounds` 为负 | 视为 0 并转 `Empty`，记警告，不崩溃 |

## 调整旋钮

| 旋钮 | 初值 | 安全范围 | 太高会怎样 | 太低会怎样 |
| --- | --- | --- | --- | --- |
| 初始解锁田块数 | 6 | 4–8 | 开局太宽松，开垦失去意义 | 开局太紧，写不下字，合字变成排队 |
| 田块总容量 | 12 | 9–18 | 选择过载 + 祟夜敌力被扩张推高 | 布局深度不足，成族/相邻玩法退化 |
| 开垦成本表 | 25→110 | 线性/指数 | 中期卡在钱上，扩张停滞 | 扩张太快，祟夜直接压死 |
| 相邻加成上限 | ×2.5 | ×1.8–×3.0 | 相邻布局成唯一解 | 相邻玩法形同虚设 |

## 视觉/音频需求

- 田块边界要**看得见但不抢戏**：浅墨线勾勒，不画格子边框（避免"表格感"）。
- 开垦：荒地→熟田的过渡要有"拓出来"的动势，不是淡入。
- 焦土：焦痕保留整季，季末随洗田一起淡去。
- 细则归 P5。

## UI需求

- 田块悬浮时显示：状态、地力、当前字（若有）、战意（若是防御字）。
- 可开垦但买不起时显示**差额**（"还差 12 铜钱"），不是灰掉就算。
- 相邻关系在拖动 `adjacent_boost` 类字时要高亮受影响的邻田。

## 验收标准

- [ ] **A1** 索引与布局：`index = row*4+col`，12 块，初始 6 块为 `Empty`，其余 `Locked`
- [ ] **A2** `neighbors(i)`：角落 2 个、边 3 个、内部 4 个，无自环、无越界
- [ ] **A3** 开垦只能按序：尝试跳过 `index 7` 直接开 `index 8` 被拒
- [ ] **A4** 开垦扣款正确，累计 370 铜钱可开满
- [ ] **A5** 铜钱不足时开垦被拒且状态零变化（与 F2 A5 联动）
- [ ] **A6** `instant` 效果生效后田转 `Empty`；`rounds:N` 正确倒计时；`season` 季末清空
- [ ] **A7** 季末洗田后所有 `Char` 转 `Empty`，但 `Soil` 不变
- [ ] **A8** 全田为 `Sui` 时不产生死锁（E3 路径可达，联合测试）
- [ ] **A9** 相邻加成叠乘不超过上限 ×2.5
- [ ] **A10** 关联性：C4/C6/C7 的 GDD 均列出 C1 为上游（文档检查）
