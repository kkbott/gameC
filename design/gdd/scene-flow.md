## 概述

P7 是所有"屏幕之间怎么走"的规则：开机、主菜单、进局、季末、通关。它是玩家情绪的**换气口**——把这个游戏和一堆弹窗隔开。

它的设计原则很短：**屏幕越少越好，动效越准越好。**

---

## 玩家幻想

> **「打开就进地里。」**

- 从点开游戏到看见田，应该在 **10 秒内**。
- 主菜单不该有一堆选项：继续、新局、设置、退出，够了。
- 季末那屏是全季情绪的落点，要像合上一本书，不是弹个报表。

---

## 详细设计

### 核心规则

**R1 · 状态机**

```
Boot（加载字表/字体/存档索引）
  → MainMenu
      ├─ 继续（有档）
      ├─ 新局（若有档 → 二次确认"将覆盖自动存档"）
      ├─ 设置（M1）
      └─ 退出
  → InGame（SeasonStart → 回合循环）
      → SeasonEnd 屏
      → GameWon 屏 / 无尽冬
```

**R2 · 主菜单最小化**

- 只有 4 个入口，**不做**"难度选择 / 角色选择 / 章节选择"。
- 最新存档显示季/回合摘要与一张缩略图（可选，成本允许再做）。
- "继续"是默认高亮项，回车直入。

**R3 · 启动与加载**

```
1. 加载字表（Addressables）      —— 显示极简进度（墨迹渗开）
2. 初始化字体图集
3. 读取存档索引
4. 进入 MainMenu
目标：冷启动到可操作 <= 10 秒
```

- **不做开场 CG、不做 logo 动画**（成本高、玩家会按掉）。
- 加载进度用**墨晕扩散**表达，不用百分比。

**R4 · 季末屏**

必须包含（顺序即优先级）：

```
1. 这一季的一句话（P3 字灵口吻，每季一句，全游戏仅 4 句）
2. 收支：产出 / 支出 / 净
3. 地力：全田平均地力与本季变化
4. 祟夜：次数、守住/漏掉、毁田数
5. 农书：本季新认得几个字
[ 进入下一季 ]
```

- **只有一个按钮**。没有"返回"，没有"重来本季"。
- 屏上文字用竖排（与农书同一规范），这是全游戏的仪式感时刻。

**R5 · 通关与无尽冬**

| 结果 | 表现 |
| --- | --- |
| 通关（冬末三波全守） | 完整的天亮转场 + 字灵一句长台词 + 农书完成度（不阻塞通关） |
| 未守住冬末 | 不停游戏，进入**无尽冬**：可继续种、继续守，收集字谱。字幕提示"今年过了，明年再来" |

- **永不出现 Game Over 屏**（与 G4 R7 一致）。
- 通关后可继续游玩，存档继续写入。

**R6 · 崩溃与大退**

- 任何时刻退出 → 回到 MainMenu 前**自动先存档**（若在合法存档点）。
- 祟夜中进行中退出 → 不可能（原子 Step），退出的存档点在其之前。

### 状态和转换

```
Boot --[加载完成]--> MainMenu
MainMenu --[继续/新局]--> InGame
InGame --[回合耗尽]--> SeasonEnd --[进入下一季]--> InGame
InGame --[冬末守住]--> GameWon --[继续]--> InGame(无尽冬)
MainMenu --[退出]--> Quit
```

### 与其他系统的交互

| 系统 | 方向 | 接口 | 所有权 |
| --- | --- | --- | --- |
| G4 季相 | 上游 | `SeasonEnded` / `GameWon` 事件 | G4 判定 |
| F4 存档 | 上游 | 加载索引、保存 | F4 拥有 |
| M1 设置 | 下游 | 设置面板 | M1 拥有 |
| F1 / P4 | 上游 | 字表与字体加载 | — |
| P3 | 下游 | 季末屏文案口吻 | P3 供文案 |

---

## 公式

```
冷启动预算：加载字表 2s + 字体 1s + 存档索引 0.5s + 菜单 0.5s ≈ 4s，上限 10s
季末屏：一季 1 次，一局 4 次
```

---

## 边缘情况

| # | 情况 | 处理 |
| --- | --- | --- |
| E1 | 无存档时点"继续" | 置灰，不报错 |
| E2 | 新局覆盖已有自动档 | 二次确认，且先备份为 `.bak`（F4） |
| E3 | 加载失败（字表/字体缺失） | 明确报错 + 提供"以最小配置进入"选项（缺字体时用 OFL 黑体兜底） |
| E4 | 季末屏时强制退出 | 季末是原子 Step；退出后重新进入从季末前开始（F4 A9） |
| E5 | 通关后再次进入 | 直接进无尽冬，不再播通关转场 |
| E6 | 窗口失焦 / Alt-Tab | 自动暂停（回合制，无实时损失），不需要额外处理 |

## 视觉/音频需求

- 主菜单用**一张实景水墨远景**，不做动态背景（省性能也省时间）。
- 季末屏转场：翻页 + 环境音淡出。
- 通关转场：天亮，全游戏最长的一段安静。
- 细则归 P5 / P6。

## UI需求

- 全部界面支持键鼠与手柄导航（与 P1 一致）。
- 退出确认必须可用手柄完成。
- 分辨率/窗口模式/垂直同步：上架必需（M1 承载）。

---

## 验收标准

- [ ] **A1** 冷启动到可操作 ≤ 10 秒（实测）
- [ ] **A2** 主菜单仅 4 项，无难度/章节选择（UI 走查）
- [ ] **A3** 季末屏仅 1 个按钮，且无"重来本季"入口（R4）
- [ ] **A4** 永不出现 Game Over 屏；冬末未守住进入无尽冬（R5）
- [ ] **A5** 新局覆盖自动档时二次确认且生成 `.bak`（E2）
- [ ] **A6** 字体缺失时降级到兜底字体仍可进入（E3）
- [ ] **A7** 全程可用手柄完成所有导航（含退出确认）
- [ ] **A8** 无开场 CG / logo 动画（A 走查）
