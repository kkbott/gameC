# T-001 · 建 Godot 工程与 Sim/View 分层

> **状态**: 已完成（2026-11-17）
> **发布人**: 创意总监
> **承接**: agent（Godot 重新立项工单）
> **对应 Sprint**: `production/sprints/sprint-01.md` 的 **T1**
> **估时**: 0.5 天

---

## 目标

在 `Client/` 下建 **Godot 4.7.2（.NET / mono）** 工程，并把规则层与表现层分开：**`Sim/` 是纯 .NET 类库（零 Godot 引用）**，**`Client/` 是 Godot View 工程**。

做完之后：`TianziGe.Sim` 能脱离 Godot 用 `dotnet test` 编译并测试，`Balance/` 控制台能引用它跑起来，Godot 工程能加载 View 脚本并引用 Sim——**这是后面所有任务的地基，也是 ADR-001 的物理落地**。

---

## 步骤（已完成）

1. 下载并校验 Godot 4.7.2 .NET 版（SHA512 见 `docs/engine-reference/godot/VERSION.md`）
2. 建 `Sim/` 纯类库：`FarmState`、`ICommand`、`Rejection`、`StepContext`、`DeterministicRng`
3. 建 `Tests/`：NUnit + 架构守卫（Sim 程序集不得引用 Godot）
4. 建 `Balance/`：最小命令循环 + FNV-1a 聚合 hash
5. 建 `Client/` Godot 工程 + `TianziGe.View.csproj`，引用 Sim
6. 写 `Bootstrap.cs`：启动时构造 `FarmState`、执行一条最小命令、打印；`--boot-probe` 时退出
7. 用 `dotnet test`、`dotnet run`、`godot --headless` 验证
8. 确认 `git status` 里没有 `.godot/`、`bin/`、`obj/` 等生成物
