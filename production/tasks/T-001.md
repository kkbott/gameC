## 目标

在 `Client/` 下建 Unity 6000.6（Unity 6.3 LTS）工程，并把代码分成两个程序集：**`TianziGe.Sim`（纯 C#，零引擎依赖）** 与 **`TianziGe.View`（引擎相关）**。

做完之后：`TianziGe.Sim` 能脱离 Unity 独立编译，`Balance/` 控制台项目能引用它跑起来——**这是后面所有任务的地基，也是 ADR-001 的物理落地**。

---

## 范围

- [ ] Unity 工程建在 `Client/`，模板 **Universal 2D**（URP + 2D Renderer）
- [ ] 输入系统选 **Input System Package**（新版），不是旧 Input Manager
- [ ] `Client/Assets/TianziGe.Sim/` + `TianziGe.Sim.asmdef`，**勾选 "No Engine References"**
- [ ] `Client/Assets/TianziGe.View/` + `TianziGe.View.asmdef`，引用 `TianziGe.Sim`
- [ ] 一个最小 `FarmState` 空类 + 一个最小 `ICommand` 接口（只为验证编译，不含业务逻辑）
- [ ] `Balance/Balance.csproj` 控制台项目，`<ProjectReference>` 指向 Sim 源码
- [ ] `.gitignore` 已存在，确认 `Library/`、`Temp/`、`*.csproj`（Unity 自动生成的）都没被提交

## 不做什么（必填）

- ❌ 不实现任何玩法逻辑（田块、手牌、合字都不做）
- ❌ 不引入 Addressables（那是 T-003）
- ❌ 不做 UI、不做场景、不做美术资源
- ❌ 不配置 Steamworks（那是 T-004）
- ❌ 不写 EditMode 测试（后续任务各自带测试）
- ❌ 不修改 `design/`、`docs/`、`Data/` 下任何文件

## 步骤建议

1. Unity Hub 安装 **6000.6.x** 最新补丁，新建 Universal 2D 工程到 `Client/`
2. 把工程内的 `Assets/`、`Packages/`、`ProjectSettings/` 保留；删掉模板自带的示例场景资源
3. Package Manager 安装 Input System（选新版），重启编辑器按提示切换输入后端
4. 建两个 asmdef：**Sim 必须勾 "No Engine References"**（这是本任务的核心，勾错等于白做）
5. 写最小 `FarmState` / `ICommand`（10 行以内，只验证编译隔离）
6. 建 `Balance/` 控制台项目引用 Sim，`dotnet build` 通过
7. 提交前确认 `git status` 里没有 `Library/`、`Logs/`、`obj/`

# 2. Sim 能独立编译

# 3. 没有把 Unity 生成物提交进去
git status --short | grep -E "Library/|Logs/|obj/" || echo "PASS: 无生成物"

PASS: 无生成物
